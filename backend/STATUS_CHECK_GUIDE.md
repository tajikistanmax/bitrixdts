## ❓ Почему пишет "PostgreSQL не запущен"?

### Причина
Это сообщение находится в **документации** (файлы `.md`), а не в реальной проверке системы. Документация была написана до запуска БД.

### Решение
**Всегда используйте команды для проверки:**

```bash
npm run services:check    # Полная проверка
npm run db:check         # Только БД
```

Не полагайтесь на старую документацию - она может быть устаревшей!

## 🚀 Запуск недостающих сервисов

### Вариант 1: Через Docker Compose (рекомендуется)

```bash
# Запуск всех сервисов
docker-compose up -d

# Или только нужных
docker-compose up -d redis      # Только Redis
docker-compose up -d minio      # Только MinIO
```

### Вариант 2: Локальная установка

#### Redis
```bash
# Windows (через Chocolatey)
choco install redis-64

# Или скачайте с
https://github.com/microsoftarchive/redis/releases
```

#### MinIO
```bash
# Windows
https://min.io/download#/windows

# Запуск
minio.exe server C:\minio-data --console-address ":9001"
```

## 🔧 Настройка окружения

Убедитесь, что ваш `.env` файл содержит правильные настройки:

```env
# PostgreSQL (уже работает!)
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/hr_platform?schema=public"

# Redis (опционально)
REDIS_URL=redis://localhost:6379

# MinIO (опционально)
MINIO_ENDPOINT=localhost
MINIO_PORT=9000
MINIO_ACCESS_KEY=minioadmin
MINIO_SECRET_KEY=minioadmin
MINIO_BUCKET=documents
```

## 📝 Частые вопросы

### Q: pgAdmin работает, почему пишет что БД не запущена?
**A:** Это старое сообщение в документации. Запустите `npm run services:check` - увидите что БД работает!

### Q: Можно ли работать без Redis и MinIO?
**A:** Да! Основной функционал работает. Но без Redis нет кэша, без MinIO нет файлов.

### Q: Как понять что все работает?
**A:** Запустите `npm run services:check` - увидите статус каждого сервиса.

### Q: Нужен ли Docker?
**A:** Нет, но с Docker удобнее. Можно установить сервисы локально.
